_Incomplete candidate profiles — a missing phone number, no availability date, an empty email field — quietly break everything downstream. An automation can't message someone it has no number for, and a filter can't match on a field that's empty. Rather than auditing profiles by hand, you can have HireData spot the gap and chase it for you._

## The pattern

Every "incomplete profile" automation is the same four pieces:

<Steps>
  <Step title="Trigger on the record changing">
    Start the automation from a **Candidate: Created or Updated** trigger (or the equivalent for the object you care about). This means the check runs whenever the profile changes, rather than on a schedule. See [Create a Carerix automation in HireData](/apps/carerix/create-a-carerix-automation-in-hiredata) for how triggers are configured.
  </Step>
  <Step title="Filter on the field being empty">
    Add a start filter for the field you want filled — for example, availability date is empty, or mobile number is empty. Only records that are actually missing the data pass the filter, so nobody gets chased for information you already have.

    The field has to be enabled on your connection before you can filter on it. See [Enable Carerix fields and relationships in automations](/apps/carerix/how-to-enable-carerix-fields-and-relationships-in-your-automations).
  </Step>
  <Step title="Add a delay (optional but recommended)">
    A short delay stops the automation firing the instant a recruiter starts typing into a half-finished profile. A day is usually enough to let normal data entry finish on its own.
  </Step>
  <Step title="Ask for the missing data">
    Then either message the candidate to ask for it, or notify the recruiter who owns the record:

    - **Ask the candidate** — start a WhatsApp conversation with a [form](/content/creating-a-form-in-hiredata) attached. The answers can be written straight back to the profile with an **Update field(s)** task, so the gap closes itself. See [How to Use Forms in WhatsApp Conversations](/apps/messaging/whatsapp/how-to-use-forms-in-whatsapp-conversations).
    - **Notify the recruiter** — send an email listing what's missing, using an [email template](/apps/messaging/emails/setting-up-an-email-template-in-hiredata) with variables for the candidate's name and the empty fields.
  </Step>
</Steps>

<Tip>
  Build one automation per field rather than one automation covering everything. It keeps the filters readable, and it means you can see at a glance which gap is the common one across your database.
</Tip>

## Before you switch it on

- **Test it first.** Run the automation against sample data so you can see which candidates it would catch and what they'd receive. See [How to Test an Automation](/automations/how-to-test-an-automation).
- **Check your safety limits.** A data-quality automation can match a large slice of your database at once. The [safety limits](/settings/automation-safety-limits) are what stop one candidate being chased repeatedly — don't switch them off for this.
- **Sync first if the data looks stale.** If fields you know are filled in Carerix still look empty in HireData, run a [manual sync](/apps/carerix/manually-sync-carerix-with-hiredata) before concluding the profile is incomplete.
