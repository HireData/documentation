Build a data-quality automation to identify candidate profiles that are missing important information, then notify someone or start a completion workflow.

## Check the template gallery first

Before building from scratch, open the Dashboard template gallery, select **All**, and filter or search for data-quality templates. Depending on your workflow, useful starting points can include:

- **Email Bounce: Schedule Task**
- **Job Application**
- **Phone Number Standardizer \+31 - Candidates - Cleanup**
- **Pre-Intake / Screening**

Open a template to review its trigger, conditions, and actions before adding it to your account.

## Build the automation

### 1. Choose the candidate trigger

In the **Start** block, select your ATS and the candidate-created or candidate-updated trigger that matches your process.

### 2. Define what counts as incomplete

Add Start conditions for the fields your team requires, such as:

- Email address
- Phone number
- First or last name
- Consent or availability
- Role, location, or other placement information

Start with one high-impact field so the first version is easy to test. You can add other conditions after confirming the workflow.

### 3. Add the completion action

Choose the action that fits your process. For example, you can:

- Create a task for a recruiter
- Notify an internal channel or email address
- Ask the candidate for the missing information
- Update the profile when the information is collected

If the source system often receives fields shortly after record creation, add a short delay that reflects your actual import process before checking the profile.

### 4. Test safely

1. Activate the automation when it is ready for testing.
2. Create or update a test candidate with the target field missing.
3. Open **Events** and inspect the event's **Data** tab.
4. Open **Runs** and confirm that the expected actions completed.

<Tip>
  If you use Carerix, confirm that each required field is enabled in the connection. See [Enable Carerix Fields and Relationships](/apps/carerix/how-to-enable-carerix-fields-and-relationships-in-your-automations) and [Carerix Webhook Fields](/apps/carerix/carerix-webhook-fields).
</Tip>

Keep account and automation safety limits enabled while testing workflows that can send candidate messages.
