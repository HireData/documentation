Use this guide when an automation did not start, stopped unexpectedly, or produced a different result than you expected.

## 1. Confirm that HireData received the event

1. Select **Events** in the main navigation.
2. Search for the candidate, contact, or event you expected to start the automation.
3. Open the event.
4. Check the **Data** tab to confirm that the expected values are present. Use the code view (`<>`) to inspect the raw JSON.

If the event is missing, check the source app and its HireData connection. HireData cannot start an automation until it receives the event.

## 2. Check the automation status

Open the automation and look at the action in the upper-right corner:

- **Pause** means the automation is active.
- **Activate** means the automation is inactive. Select **Activate** when you are ready for new events to enter the automation.

Activating an automation does not automatically process events that arrived while it was inactive. Replay the event after you have checked the automation configuration.

## 3. Compare the event with the Start configuration

Open the automation's **Start** block and compare its app, trigger, and conditions with the event's **Data** tab.

Check for:

- A different object or trigger than the event used
- A missing field
- A value that does not satisfy a condition
- A field whose name or format changed in the source app

If you change the Start configuration, save the automation before testing again.

## 4. Inspect the run

If the event started the automation, select **Runs** in the main navigation and open the relevant row. Select the step that stopped or was cancelled, then review its **Overview**, **Fields**, and **Related** tabs.

For cancellation messages and their fixes, see [Run Cancellation Reasons](/knowledge-base/run-cancellation-reasons).

## 5. Test with Replay

After fixing the cause:

1. Return to the event.
2. Select **Replay**.
3. Confirm that the new run completes as expected.

<Warning>
  Replay can repeat messages, updates, tasks, and other actions that already completed. Inspect the earlier run before replaying an event.
</Warning>

If the event still does not enter the automation, record the event ID, automation name, and expected trigger before contacting HireData Support.
