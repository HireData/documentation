_Personal access tokens (`hdp_…`) let a script or AI assistant use the HireData MCP endpoint (`https://api.hiredata.com/mcp`) without an interactive sign-in. Scopes control which MCP tools a token can call. This page lists every scope, grouped the same way as in the token settings and on the OAuth consent screen._

## How scopes work

- A token can never do more than you can. Every call is checked against the token's scopes **and** your own permissions in the workspace it runs in.
- Each group's manage scope implies the narrower scopes in the same group. A token with `people.manage` can use every tool listed under `people.read`, `people.write`, and `people.delete`.
- Which scopes you can grant depends on your role. Scopes you don't hold yourself aren't offered when creating a token, and some groups below may not appear for you.
- Scope changes on an existing token apply immediately. The token secret stays the same.

## Available with any token {#any-token}

These tools don't require a scope:

`whoami`, `listWorkspaces`, `searchKnowledgeBase`, `getKnowledgeBaseContent`

## Shared templates {#system-templates}

The shared HireData template catalog and its labels.

<Info>
  This scope is only available to HireData super admins.
</Info>

| Scope | Grants | MCP tools |
| --- | --- | --- |
| `system.templates.manage` | Manage the shared template catalog | `listTemplateTags`, `showTemplateTag`, `createTemplateTag`, `updateTemplateTag`, `deleteTemplateTag`, and the automation trigger tools (`listAutomationTriggers`, `showAutomationTrigger`, `showAutomationTriggerCapabilities`, `createAutomationTrigger`, `updateAutomationTrigger`, `deleteAutomationTrigger`, `duplicateAutomationTrigger`, `restoreAutomationTrigger`) |

## Users {#users}

Users and invitations within your workspaces.

| Scope | Grants | MCP tools |
| --- | --- | --- |
| `users.read` | View users | `listUsers`, `showUser`, `listUserInvites` |
| `users.manage` | Manage users | Everything under `users.read`, plus `createUser`, `updateUser`, `deleteUser`, `inviteUsers`, `revokeUserInvite` |

## People {#people}

People, their contact details, labels, and source history in your workspaces.

| Scope | Grants | MCP tools |
| --- | --- | --- |
| `people.read` | View people | `listPeople`, `showPerson` |
| `people.write` | Create and update people | `createPerson`, `updatePerson` |
| `people.delete` | Delete people | `deletePerson` |
| `people.manage` | Manage people | Everything under `people.read`, `people.write`, and `people.delete` |

## Automations {#automations}

Your automations, their triggers and run history.

| Scope | Grants | MCP tools |
| --- | --- | --- |
| `automations.read` | View automations | No MCP tools use this scope yet |
| `automations.manage` | Manage automations | No MCP tools use this scope yet |
