This guide walks you through setting up an OTYS automation in HireData. With this integration, you can automate tasks such as sending Candidate NPS surveys to improve candidate experiences and streamline your recruitment processes. Follow each step below to set up the automation.

## Step 1: Set up the trigger

After you've [set up the connection with OTYS](/apps/otys/connect-with-otys), the first step in setting up an OTYS automation is to define the trigger. A trigger makes sure HireData "listens" to certain events occurring within OTYS. Select all relationships you'll need later on. For example, select a candidate when you want to send them a survey in a later step of the automation. Here's how to do it:

_Example trigger: Procedure: Created or Updated_

_Select the related objects you'll need later on in the automation, e.g. a user you want to be the sender of a message and the recipient(s) of that message_
