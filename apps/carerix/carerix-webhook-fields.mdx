Carerix events contain the fields enabled for the relevant object in your Carerix connection. Use each field's key when you need to identify it in an event or automation.

## Candidate fields at a glance

The standard Candidate object includes these commonly used fields:

| Field | Key | Typical use |
| --- | --- | --- |
| Id | `{{_id}}` | Identify the Carerix record |
| First Name | `{{firstName}}` | Personalize messages and updates |
| Last Name | `{{lastName}}` | Personalize messages and updates |
| Email Address | `{{emailAddress}}` | Use the main email field |
| Business Email Address | `{{businessEmailAddress}}` | Use the business email field |
| Private Email Address | `{{privateEmailAddress}}` | Use the private email field |
| Primary Email Address | `{{primaryEmailAddress}}` | Use Carerix's primary email field |
| Any Email Address | `{{anyEmailAddress}}` | Select an email using HireData's fallback order |

Your available fields can differ because each connection has its own enabled field set. For the fallback behavior of `{{anyEmailAddress}}`, see [Combined Fields](/apps/carerix/combined-fields-explained).

## Confirm the fields in your connection

1. Go to **Settings** \> **Apps**.
2. Open **Carerix**.
3. Open the three-dot menu for the connection and select **Edit**.
4. Select an object, such as **Candidate**, **Contact**, **Meeting**, or **User**.
5. Review the **Object Definition** table. It shows each field's **Label**, **Type**, and **Key**.

Only enabled fields are available to new events. To change the set, see [Enable Carerix Fields and Relationships](/apps/carerix/how-to-enable-carerix-fields-and-relationships-in-your-automations).

## Inspect the exact event payload

To confirm what HireData received for a particular record:

1. Select **Events** in the main navigation.
2. Open the relevant Carerix event.
3. Select the **Data** tab.
4. Select the code view (`<>`) to inspect the raw JSON.

Use the **Runs** tab to see which automations processed the event.

## Carerix event types

When you configure a Carerix Start block, the trigger picker can include:

- **Created**
- **Created or Updated**
- **Updated**
- **Schedule**
- **Manual**

Choose the trigger that matches when the automation should start. **Deleted** is not currently offered in the trigger picker.
