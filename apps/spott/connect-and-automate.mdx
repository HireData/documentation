Connect Spott once, and changes in Spott start your HireData automations. An application that moves stage can send the candidate a WhatsApp message, a placement start date can trigger a check-in a week later, and every Spott field can be used in your emails, WhatsApp messages and forms.

## Before you start

- You need a Spott user who can create API keys and webhook endpoints in Spott.
- You need a HireData admin to add the app.

## Step 1: Connect Spott

1. Go to **Settings** > [**Apps**](https://app.hiredata.com/settings/apps). Spott is listed at the top.
2. Open **Spott** and click **Connect**.
3. In Spott, create a new API key and copy it.
4. Paste the API key in HireData. The **Public slug** is optional.
5. Save. HireData checks the key with Spott before it saves the connection.

When the connection is saved, HireData syncs your Spott field definitions and users. The **Data sync** timeline on the **General** tab shows each step.

<Note>
  The first sync doesn't import all your Spott records. Records come in when they change in Spott, when an automation looks them up, or when a scheduled automation runs.
</Note>

## Step 2: Add the webhook in Spott

Spott tells HireData about changes through a webhook. You set it up once, in Spott.

1. On the **General** tab of the Spott connection, copy the webhook URL.
2. In Spott, add a new webhook endpoint and paste the URL.
3. Select all events, and create the endpoint.
4. Copy the signing secret Spott shows you.
5. In HireData, open the **Settings** tab of the Spott connection and paste it under **Webhook signing secret**. Save.

HireData only accepts events signed with this secret, so the webhook doesn't work without it.

**Check it works:** change a test candidate in Spott. The **General** tab then shows when the last event arrived, and the event is listed on the **Events** tab.

## Step 3: Create your first Spott automation

1. Go to [**Automations**](https://app.hiredata.com/automations) and create a new automation.
2. Pick a Spott object. Objects are grouped the way Spott groups them: ATS, CRM, Workspace, Tools and Admin. Names follow Spott, so you'll see **Job** and **Client**.
3. Choose how the automation starts:
   - **An event**, such as an application being created, updated or moved to another stage, or an opportunity being created, updated, deleted or moved to another stage.
   - **A custom date**, such as one week after a placement's start date.
   - **A schedule**, such as every Monday for a set of records.
   - **Manual**, to run it by hand for one record.

### Only start for one track or stage

If you use several pipeline tracks in Spott, you can limit an application automation to one track, and to a stage within that track.

- Add a start filter on **Stage track IDs** to pick the track.
- Add a start filter on **Stage ID** to pick the stage. Stages with the same name show their track next to them, so you can tell them apart.

An application in another track won't start the automation, even when its stage has the same name.

<Tip>
  **Track ID** is marked **(legacy)** because Spott plans to remove it. Use **Stage track IDs** instead; it works the same way in filters.
</Tip>

### Scheduled automations

A scheduled automation only offers the filters Spott itself can search on. To narrow the audience further, add a **Filter** step after the start.

Spott doesn't report how many records match, so the builder can't show the audience size up front. The automation still goes through every matching record.

## Use Spott data in your messages

- Every synced Spott field is available in emails, WhatsApp messages and forms.
- Linked records come along: an application includes its candidate and job, and a placement includes its candidate, client and job.
- Application and job scorecards are available.
- Clients show their last interaction date and who it was with.

To see which fields came in for a record, open the event on the **Events** tab, or browse the object in **Collections**.

## What Spott can't do yet

These depend on what Spott's API offers today.

- **Placement status:** Spott has no status field on placements. Use a custom field in Spott instead.
- **Email history:** emails sent from HireData don't appear in Spott's email history.
- **Appointments:** Spott can't list all appointments, so an automation can't start on an appointment date.
