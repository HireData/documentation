Email est une zone d'une seule ligne qui doit contenir une adresse e-mail. Le répondant voit un signe @ dans la zone vide, et une adresse mal formée ne passe pas.

Il se trouve dans le groupe **Contact Info** de la palette **Add Content**.

## Paramètres

La carte porte les [paramètres partagés par tous les champs](/fr/reference/forms/overview#settings-every-field-shares). Email ajoute les quatre mêmes qu'un champ de texte.

- **Placeholder**, jusqu'à 255 caractères, affiché dans la zone vide.
- **Minimum Length** et **Maximum Length**, comptés en caractères.
- **Validation Pattern**, une expression régulière à laquelle la réponse doit correspondre, en plus du contrôle d'adresse.

Le message que voit un répondant lorsque l'adresse est mal formée se trouve sous **Validation** dans [Langues et traductions](/fr/reference/forms/overview#localization), sous le nom **Invalid Email**.

## Ce que le champ stocke

Du texte, l'adresse telle que le répondant l'a saisie.

## Opérateurs de logique

| Opérateur | Correspond quand |
|---|---|
| has response | le répondant a répondu, quelle que soit la réponse |
| is equal to | la réponse est exactement la valeur |
| is not equal to | la réponse est n'importe quoi d'autre |
| starts with | la réponse commence par la valeur |
| ends with | la réponse se termine par la valeur |
| contains | la valeur apparaît quelque part dans la réponse |
| does not contain | la valeur n'apparaît nulle part dans la réponse |

**ends with** est le plus utile ici. Une règle du type `if email ends with @yourcompany.com` distingue un répondant interne d'un répondant externe.

![L'onglet Logic avec le sélecteur d'opérateur ouvert sur une condition Email, listant has response, is equal to, is not equal to, starts with, ends with, contains et does not contain](/images/forms-builder/fields/operators-email.png)

## Évaluation

Activez **Criteria**, **Scoring** ou **Skills** pour le formulaire dans l'[onglet Evaluation](/fr/reference/forms/evaluation/overview) et chacun obtient un interrupteur sur cette carte. Une adresse dit rarement quelque chose d'un candidat, si bien que la plupart des formulaires laissent les trois désactivés ici.
