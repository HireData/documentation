A run records how an event moved through an automation. Use it to see which steps completed, stopped, or were cancelled.

## Find a run

1. Select **Runs** in the main navigation.
2. Search the list or use its columns to identify the run. The list includes details such as state, automation, step, creation time, update time, and owner.
3. Select the run row to open its details.

If a row is difficult to open, select an empty area of the row instead of its linked text.

## Inspect the timeline

The run timeline lists each automation step and its result. Select a step to inspect it.

The step details can include:

- **Overview** for the result, cancellation reason, or error message
- **Fields** for values used or produced by the step
- **Related** for associated records

For a cancelled Send Email step, select it in the timeline and read the exact message on **Overview**. For example, the message can be `Invalid sender email.`

See [Run Cancellation Reasons](/knowledge-base/run-cancellation-reasons) for common causes and fixes.

## Continue troubleshooting

Open the related event and compare its **Data** tab with the automation's Start conditions. If you correct the configuration, you can replay the event, but first confirm which actions the earlier run already completed.

<Warning>
  Replay can repeat messages, record updates, tasks, and other actions from the earlier run.
</Warning>
