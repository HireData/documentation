O plugin da HireData é a forma mais rápida de obter as [cinco skills da HireData](/apps/mcp/hiredata-skills) — plan an activation, create triggers, create forms, create email templates e create WhatsApp templates — no ChatGPT, Codex ou Claude, juntamente com a ligação MCP oficial da HireData. As skills ensinam o seu assistente a planear, criar, testar e melhorar automações da HireData, em vez de lhe darem apenas ferramentas sem o método de trabalho por trás delas.

<Note>
  O plugin está atualmente disponível como instalação em acesso antecipado a partir do marketplace público da HireData no GitHub. Ainda não aparece no Plugins Directory universal da OpenAI. Use estes passos com a app de desktop do ChatGPT, o Codex CLI, o Claude Code ou uma organização Claude Team/Enterprise. Para o Gemini ou uma ligação apenas por MCP, [ligue a HireData ao seu assistente de IA](/apps/mcp/connect-hiredata-to-your-ai-assistant).
</Note>

## O que o plugin acrescenta

A primeira versão inclui cinco skills — consulte [Skills da HireData para o seu assistente de IA](/apps/mcp/hiredata-skills) para saber o que cada uma faz e ver prompts de exemplo:

- [**Plan an activation**](/apps/mcp/hiredata-skills#plan-an-activation) — associa problemas do cliente a fluxos de trabalho da HireData de alto impacto e a resultados mensuráveis.
- [**Create triggers**](/apps/mcp/hiredata-skills#create-triggers) — escolha o evento, o timing, os filtros e as relações certas antes de criar um trigger.
- [**Create forms**](/apps/mcp/hiredata-skills#create-forms) — desenhe formulários concisos com validação, ramificação e um próximo passo claro.
- [**Create email templates**](/apps/mcp/hiredata-skills#create-email-templates) — use variáveis, modificadores e variáveis de IA controladas em segurança.
- [**Create WhatsApp templates**](/apps/mcp/hiredata-skills#create-whatsapp-templates) — desenhe templates concisos e contextuais, com um raciocínio adequado sobre a categoria e caminhos de acompanhamento.

O plugin também configura a ligação remota existente do MCP da HireData em `https://api.hiredata.com/mcp`. Não inclui nem implementa um servidor MCP separado.

| Instalação | O que obtém | Use quando |
| --- | --- | --- |
| Plugin da HireData | Cinco skills da HireData e a ligação MCP | Usa o ChatGPT desktop, o Codex ou o Claude e quer tanto o conhecimento como as ferramentas da HireData |
| Apenas MCP | Ferramentas ao vivo da HireData sem as cinco skills | Usa o Gemini, outro cliente MCP, um plano Claude individual sem catálogo de organização, ou só precisa de acesso às ferramentas |

## Antes de começar

Precisa de:

- Uma conta HireData com acesso a pelo menos um workspace.
- Para ChatGPT ou Codex: a app de desktop atual do ChatGPT ou o Codex CLI com suporte para `codex plugin`.
- Para Claude: Claude Code, ou uma organização Claude Team/Enterprise com Cowork e Skills ativados.
- Permissão para adicionar marketplaces de Git e ligações MCP. O administrador de IA da sua organização pode restringir estas funcionalidades.

## Instalar o plugin no ChatGPT ou Codex

<Steps>
  <Step title="Adicione o marketplace da HireData">
    Abra um terminal e execute:

    ```bash
    codex plugin marketplace add HireData/skills
    ```

    Isto adiciona o repositório público da HireData no GitHub como o marketplace `hiredata-skills`. Não precisa de clonar o repositório.
  </Step>
  <Step title="Instale a HireData">
    Execute:

    ```bash
    codex plugin add hiredata@hiredata-skills
    ```

    Siga qualquer instrução de configuração apresentada pelo Codex. O código-fonte do plugin é público em [github.com/HireData/skills](https://github.com/HireData/skills).
  </Step>
  <Step title="Recarregue o plugin">
    Inicie uma nova sessão do Codex. Se usa a app de desktop do ChatGPT, reinicie-a, abra **Plugins** e confirme que **HireData** aparece em **Installed** ou no marketplace **HireData Skills**.

    As skills e ferramentas instaladas são carregadas quando inicia uma nova conversa. Não aparecem retroativamente numa conversa já existente.
  </Step>
  <Step title="Ligue a sua conta HireData">
    Quando lhe for pedido, inicie sessão na HireData. Selecione o workspace ou workspaces que o assistente pode usar, reveja as permissões pedidas e clique em **Authorize**.

    O assistente recebe apenas o acesso ao workspace que selecionar e trabalha com as suas permissões existentes na HireData. Consulte [como funcionam o acesso e a segurança da HireData](/apps/mcp/connect-hiredata-to-your-ai-assistant#how-access-and-security-work).
  </Step>
  <Step title="Verifique a instalação">
    Confirme o plugin instalado a partir do terminal:

    ```bash
    codex plugin list --marketplace hiredata-skills
    ```

    Depois experimente um destes pedidos numa nova conversa:

    - "Usa a HireData para rever os nossos templates existentes e ordenar o fluxo de trabalho em falta com maior impacto. Não crias nada ainda."
    - "Usa a HireData para desenhar um email de confirmação de candidatura que use uma variável de IA em segurança. Mostra-me uma pré-visualização e não o envies."
    - "Usa a HireData para criar um formulário de disponibilidade de candidato. Mostra-me o formulário e a lógica de ramificação antes de o criar."
  </Step>
</Steps>

## Instalar o plugin no Claude

Instalar o plugin também configura a ligação MCP da HireData, pelo que não é necessária qualquer configuração de conector em separado.

### Claude Code

Execute estes comandos dentro do Claude Code:

```bash
/plugin marketplace add HireData/skills
/plugin install hiredata@hiredata-skills
```

Inicie sessão na HireData quando lhe for pedido na primeira utilização, selecione os workspaces permitidos e autorize. Inicie uma nova conversa antes de testar. As skills têm o namespace `/hiredata:hiredata-plan-activation` e assim por diante.

### Claude Team e Enterprise (web, desktop e Cowork)

Um Owner da organização distribui o plugin através do catálogo da organização:

<Steps>
  <Step title="Adicione o marketplace">
    Abra **Organization settings → Plugins** e adicione um marketplace sincronizado com o GitHub com o repositório `HireData/skills`. A sincronização inicial é executada automaticamente, e as versões seguintes do plugin são sincronizadas a partir do branch predefinido do repositório.

    Em alternativa, adicione um marketplace personalizado e carregue o plugin como ficheiro ZIP (o diretório `plugins/hiredata` do repositório). Use esta opção quando a sua organização preferir não sincronizar a partir do GitHub; note que os carregamentos manuais não recebem atualizações automáticas.
  </Step>
  <Step title="Torne o plugin disponível">
    Defina a preferência de instalação do plugin da HireData, por exemplo **Available for install** ou **Installed by default**.
  </Step>
  <Step title="Instale como membro">
    Os membros abrem o navegador de plugins a partir da interface de chat, instalam a **HireData** e concluem o início de sessão na HireData na primeira utilização. O plugin funciona depois no chat web do Claude, na app de desktop do Claude e em sessões do Cowork. Se o Owner tiver definido o plugin como **Installed by default**, os membros saltam completamente este passo.
  </Step>
</Steps>

Os planos Claude individuais sem catálogo de organização podem [instalar as skills com um prompt](#install-the-skills-with-a-prompt) e combiná-las com a [ligação MCP manual](/apps/mcp/connect-hiredata-to-your-ai-assistant).

## Instalar as skills com um prompt

Sem suporte para plugins no seu plano ou assistente? As skills são ficheiros públicos e simples, por isso pode deixar o seu assistente de IA obtê-los e empacotá-los por si.

### Claude (chat, desktop e Cowork)

Copie este prompt para uma conversa do Claude com capacidade para criar ficheiros (por exemplo, uma sessão Cowork):

```text
Download the five HireData skills from https://github.com/HireData/skills
(they are in plugins/hiredata/skills). Package each skill as a separate
.skill file — a ZIP with that skill's SKILL.md and references folder at
its root — and send me the five files so I can save them as skills on my
account.
```

Guarde cada ficheiro que o Claude entregar como uma skill na sua conta. Combinado com o [conector MCP da HireData](/apps/mcp/connect-hiredata-to-your-ai-assistant), isto dá-lhe o mesmo comportamento que o plugin completo. Se a sua organização não permitir guardar skills, peça a um Owner para distribuir o plugin através do catálogo da organização.

### Qualquer outro assistente

Assistentes sem skills instaláveis podem ainda seguir uma skill para uma única tarefa. Substitua o nome da skill e o seu objetivo neste prompt:

```text
Fetch https://raw.githubusercontent.com/HireData/skills/main/plugins/hiredata/skills/hiredata-plan-activation/SKILL.md,
follow the workflow it describes (fetch the files it references too), and
help me with: [your goal]
```

Isto funciona no ChatGPT, no Gemini, no Microsoft Copilot ou em qualquer assistente que consiga ler páginas web públicas, e combina bem com a [ligação MCP manual](/apps/mcp/connect-hiredata-to-your-ai-assistant). Os nomes das cinco pastas são `hiredata-plan-activation`, `hiredata-create-triggers`, `hiredata-create-forms`, `hiredata-create-email-templates` e `hiredata-create-whatsapp-templates`.

## Atualizar o plugin

- **ChatGPT ou Codex:** execute `codex plugin marketplace upgrade hiredata-skills` e depois abra **Plugins** ou execute `/plugins` no Codex CLI para aplicar a atualização.
- **Claude Code:** execute `/plugin marketplace update hiredata-skills`.
- **Claude Team e Enterprise:** os marketplaces sincronizados com o GitHub atualizam-se automaticamente quando a HireData publica uma nova versão do plugin. Os ZIPs carregados manualmente exigem um novo carregamento.

Inicie uma nova conversa depois de atualizar para que o seu assistente carregue as novas skills e a configuração.

## Resolução de problemas

- **O comando `codex plugin` não está disponível:** atualize o Codex ou a app de desktop do ChatGPT e tente novamente.
- **O marketplace da HireData não aparece:** execute `codex plugin marketplace list` e depois reinicie a app de desktop do ChatGPT.
- **O plugin está instalado mas as suas skills não aparecem:** ative a HireData em **Plugins** e inicie uma nova conversa.
- **A HireData não lhe pede para iniciar sessão:** inicie uma nova conversa com o plugin ativado e faça um pedido que precise de dados de um workspace da HireData.
- **A sua organização bloqueia a instalação:** peça ao administrador do ChatGPT ou do Codex para permitir o marketplace da HireData e a ligação MCP.
- **As skills não são acionadas no Claude:** confirme que o plugin aparece como instalado (`/plugin` no Claude Code, ou o navegador de plugins numa organização Claude) e inicie uma nova conversa.
- **Só precisa das ferramentas MCP ou usa outro assistente:** siga o [guia de ligação MCP manual](/apps/mcp/connect-hiredata-to-your-ai-assistant).

## Remover o plugin

- **ChatGPT ou Codex:** execute `codex plugin remove hiredata@hiredata-skills`.
- **Claude Code:** execute `/plugin uninstall hiredata@hiredata-skills`.
- **Claude Team e Enterprise:** remova o plugin no navegador de plugins ou peça a um Owner para alterar a sua disponibilidade em **Organization settings → Plugins**. Os plugins marcados como **Required** por um Owner não podem ser removidos pelos membros.

Remover o plugin não revoga necessariamente uma autorização OAuth existente da HireData. Desligue a HireData no seu assistente de IA ou revogue a autorização nas definições da HireData quando também quiser remover o acesso.
