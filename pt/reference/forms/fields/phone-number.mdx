Phone Number é uma caixa de uma só linha para um número de telefone. O inquirido vê um símbolo de auscultador na caixa vazia.

Fica no grupo **Contact Info** da paleta **Add Content**.

## Definições

O cartão tem as [definições que todos os campos partilham](/pt/reference/forms/overview#settings-every-field-shares). Phone Number acrescenta as mesmas quatro de um campo de texto.

- **Placeholder**, até 255 caracteres, mostrado na caixa vazia.
- **Minimum Length** e **Maximum Length**, contados em caracteres.
- **Validation Pattern**, uma expressão regular à qual a resposta tem de corresponder.

Não há uma mensagem de validação específica de telefone, por isso **Validation Pattern** é a forma de insistir num formato. Se o seu processo precisa de números em formato internacional, peça-o na **Description** e reforce-o com um padrão.

## O que armazena

Texto, o número tal como o inquirido o escreveu. A HireData não o reformata.

## Operadores de lógica

| Operador | Corresponde quando |
|---|---|
| has response | o inquirido deu alguma resposta |
| is equal to | a resposta é exatamente o valor |
| is not equal to | a resposta é qualquer outra coisa |
| starts with | a resposta começa pelo valor |
| ends with | a resposta termina no valor |
| contains | o valor aparece algures na resposta |
| does not contain | o valor não aparece em lado nenhum da resposta |

![O separador Logic com o seletor de operadores aberto numa condição de Phone Number, a listar has response, is equal to, is not equal to, starts with, ends with, contains e does not contain](/images/forms-builder/fields/operators-phone-number.png)

## Avaliação

Ative **Criteria**, **Scoring** ou **Skills** para o formulário no [separador Evaluation](/pt/reference/forms/evaluation/overview) e cada um ganha um interruptor neste cartão. Um número raramente vale a pena avaliar, por isso a maioria dos formulários deixa os três desligados aqui.
