De HireData-plugin is de snelste manier om [HireData's vijf skills](/apps/mcp/hiredata-skills) (een activatie plannen, triggers aanmaken, formulieren aanmaken, e-mailtemplates aanmaken en WhatsApp-templates aanmaken) in ChatGPT, Codex of Claude te krijgen, samen met HireData's officiële MCP-verbinding. De skills leren je assistent hoe hij HireData-automatiseringen kan plannen, aanmaken, testen en verbeteren, in plaats van dat hij tools krijgt zonder de bijbehorende werkwijze.

<Note>
  De plugin is momenteel beschikbaar als early-access installatie vanuit HireData's publieke GitHub-marketplace. Hij verschijnt nog niet in OpenAI's universele Plugins Directory. Gebruik deze stappen met de ChatGPT-desktop-app, de Codex CLI, Claude Code, of een Claude Team/Enterprise-organisatie. Voor Gemini of een alleen-MCP-verbinding, [verbind HireData met je AI-assistent](/apps/mcp/connect-hiredata-to-your-ai-assistant).
</Note>

## Wat de plugin toevoegt

De eerste release bevat vijf skills. Zie [HireData-skills voor je AI-assistent](/apps/mcp/hiredata-skills) voor wat elke skill doet en voorbeeldprompts:

- [**Plan an activation**](/apps/mcp/hiredata-skills#plan-an-activation) — koppel klantproblemen aan impactvolle HireData-workflows en meetbare resultaten.
- [**Create triggers**](/apps/mcp/hiredata-skills#create-triggers) — kies de juiste gebeurtenis, timing, filters en relaties voordat je een trigger aanmaakt.
- [**Create forms**](/apps/mcp/hiredata-skills#create-forms) — ontwerp beknopte formulieren met validatie, branching en een duidelijke vervolgstap.
- [**Create email templates**](/apps/mcp/hiredata-skills#create-email-templates) — gebruik variabelen, modifiers en begrensde AI-variabelen op een veilige manier.
- [**Create WhatsApp templates**](/apps/mcp/hiredata-skills#create-whatsapp-templates) — ontwerp beknopte, contextuele templates met passende categorie-onderbouwing en vervolgpaden.

De plugin configureert ook de bestaande externe HireData MCP-verbinding op `https://api.hiredata.com/mcp`. Hij bundelt of installeert geen aparte MCP-server.

| Installatie | Wat je krijgt | Wanneer gebruiken |
| --- | --- | --- |
| HireData-plugin | Vijf HireData-skills en de MCP-verbinding | Je gebruikt ChatGPT desktop, Codex of Claude en wilt zowel HireData-kennis als tools |
| Alleen MCP | Live HireData-tools zonder de vijf skills | Je gebruikt Gemini, een andere MCP-client, een individueel Claude-abonnement zonder organisatiecatalogus, of hebt alleen toegang tot tools nodig |

## Voordat je begint

Je hebt nodig:

- Een HireData-account met toegang tot ten minste één workspace.
- Voor ChatGPT of Codex: een actuele ChatGPT-desktop-app of Codex CLI met ondersteuning voor `codex plugin`.
- Voor Claude: Claude Code, of een Claude Team/Enterprise-organisatie met Cowork en Skills ingeschakeld.
- Rechten om Git-marketplaces en MCP-verbindingen toe te voegen. De AI-beheerder van je organisatie kan deze functies beperken.

## Installeer de plugin in ChatGPT of Codex

<Steps>
  <Step title="Voeg de HireData-marketplace toe">
    Open een terminal en voer uit:

    ```bash
    codex plugin marketplace add HireData/skills
    ```

    Hiermee wordt HireData's publieke GitHub-repository toegevoegd als de `hiredata-skills`-marketplace. Je hoeft de repository niet te clonen.
  </Step>
  <Step title="Installeer HireData">
    Voer uit:

    ```bash
    codex plugin add hiredata@hiredata-skills
    ```

    Volg eventuele setup-prompts die Codex toont. De bron van de plugin is publiek beschikbaar op [github.com/HireData/skills](https://github.com/HireData/skills).
  </Step>
  <Step title="Herlaad de plugin">
    Start een nieuwe Codex-sessie. Als je de ChatGPT-desktop-app gebruikt, herstart hem, open **Plugins** en controleer of **HireData** verschijnt onder **Installed** of de **HireData Skills**-marketplace.

    Geïnstalleerde skills en tools worden geladen wanneer je een nieuw gesprek start. Ze verschijnen niet met terugwerkende kracht in een bestaand gesprek.
  </Step>
  <Step title="Koppel je HireData-account">
    Log in bij HireData wanneer daarom wordt gevraagd. Selecteer de workspace of workspaces die de assistent mag gebruiken, controleer de gevraagde rechten en klik op **Authorize**.

    De assistent krijgt alleen de workspace-toegang die je selecteert en werkt met je bestaande HireData-rechten. Zie [hoe toegang en beveiliging in HireData werken](/apps/mcp/connect-hiredata-to-your-ai-assistant#how-access-and-security-work).
  </Step>
  <Step title="Controleer de installatie">
    Bekijk de geïnstalleerde plugin vanuit de terminal:

    ```bash
    codex plugin list --marketplace hiredata-skills
    ```

    Probeer daarna een van deze verzoeken in een nieuw gesprek:

    - "Gebruik HireData om onze bestaande templates te bekijken en de meest impactvolle ontbrekende workflow te rangschikken. Maak nog niets aan."
    - "Gebruik HireData om een sollicitatiebevestigingsmail te ontwerpen die een AI-variabele veilig gebruikt. Toon me een preview en verstuur hem niet."
    - "Gebruik HireData om een formulier voor kandidaatbeschikbaarheid aan te maken. Toon me het formulier en de branching-logica voordat je het aanmaakt."
  </Step>
</Steps>

## Installeer de plugin in Claude

Het installeren van de plugin configureert ook de HireData MCP-verbinding, dus een aparte connector-setup is niet nodig.

### Claude Code

Voer deze commando's uit in Claude Code:

```bash
/plugin marketplace add HireData/skills
/plugin install hiredata@hiredata-skills
```

Log bij het eerste gebruik in bij HireData wanneer daarom wordt gevraagd, selecteer de toegestane workspaces en autoriseer. Start een nieuw gesprek voordat je gaat testen. Skills hebben een namespace zoals `/hiredata:hiredata-plan-activation` enzovoort.

### Claude Team en Enterprise (web, desktop en Cowork)

Een Owner van de organisatie verspreidt de plugin via de organisatiecatalogus:

<Steps>
  <Step title="Voeg de marketplace toe">
    Open **Organization settings → Plugins** en voeg een GitHub-gesynchroniseerde marketplace toe met de repository `HireData/skills`. De eerste synchronisatie start automatisch, en latere plugin-releases worden vanuit de default branch van de repository gesynchroniseerd.

    Voeg als alternatief een custom marketplace toe en upload de plugin als ZIP-bestand (de map `plugins/hiredata` uit de repository). Gebruik dit wanneer je organisatie liever niet vanuit GitHub synchroniseert. Handmatige uploads ontvangen geen automatische updates.
  </Step>
  <Step title="Maak de plugin beschikbaar">
    Stel de installatievoorkeur van de HireData-plugin in, bijvoorbeeld **Available for install** of **Installed by default**.
  </Step>
  <Step title="Installeer als lid">
    Leden openen de plugin-browser vanuit de chatinterface, installeren **HireData** en voltooien bij het eerste gebruik de HireData-login. Daarna werkt de plugin in Claude webchat, de Claude-desktop-app en Cowork-sessies. Als de Owner de plugin op **Installed by default** heeft ingesteld, kunnen leden deze stap volledig overslaan.
  </Step>
</Steps>

Individuele Claude-abonnementen zonder organisatiecatalogus kunnen [de skills installeren met een prompt](#install-the-skills-with-a-prompt) en die combineren met de [handmatige MCP-verbinding](/apps/mcp/connect-hiredata-to-your-ai-assistant).

## Installeer de skills met een prompt

Geen plugin-ondersteuning op je abonnement of assistent? De skills zijn gewone, openbare bestanden, dus je kunt je AI-assistent ze voor je laten ophalen en verpakken.

### Claude (chat, desktop en Cowork)

Kopieer deze prompt in een Claude-gesprek dat bestanden kan aanmaken (bijvoorbeeld een Cowork-sessie):

```text
Download the five HireData skills from https://github.com/HireData/skills
(they are in plugins/hiredata/skills). Package each skill as a separate
.skill file — a ZIP with that skill's SKILL.md and references folder at
its root — and send me the five files so I can save them as skills on my
account.
```

Sla elk bestand dat Claude aanlevert op als skill op je account. Gecombineerd met de [HireData MCP-connector](/apps/mcp/connect-hiredata-to-your-ai-assistant) krijg je hetzelfde gedrag als de volledige plugin. Als je organisatie het opslaan van skills niet toestaat, vraag dan een Owner om de plugin via de organisatiecatalogus te verspreiden.

### Elke andere assistent

Assistenten zonder installeerbare skills kunnen een skill nog steeds volgen voor een enkele taak. Vervang de naam van de skill en je doel in deze prompt:

```text
Fetch https://raw.githubusercontent.com/HireData/skills/main/plugins/hiredata/skills/hiredata-plan-activation/SKILL.md,
follow the workflow it describes (fetch the files it references too), and
help me with: [your goal]
```

Dit werkt in ChatGPT, Gemini, Microsoft Copilot of elke assistent die openbare webpagina's kan lezen, en past goed bij de [handmatige MCP-verbinding](/apps/mcp/connect-hiredata-to-your-ai-assistant). De vijf mapnamen zijn `hiredata-plan-activation`, `hiredata-create-triggers`, `hiredata-create-forms`, `hiredata-create-email-templates` en `hiredata-create-whatsapp-templates`.

## De plugin bijwerken

- **ChatGPT of Codex:** voer `codex plugin marketplace upgrade hiredata-skills` uit, open daarna **Plugins** of voer `/plugins` uit in de Codex CLI om de update toe te passen.
- **Claude Code:** voer `/plugin marketplace update hiredata-skills` uit.
- **Claude Team en Enterprise:** GitHub-gesynchroniseerde marketplaces worden automatisch bijgewerkt wanneer HireData een nieuwe pluginversie publiceert. Handmatig geüploade ZIPs vereisen een nieuwe upload.

Start een nieuw gesprek na de update, zodat je assistent de nieuwe skills en configuratie laadt.

## Problemen oplossen

- **Het `codex plugin`-commando is niet beschikbaar:** werk Codex of de ChatGPT-desktop-app bij en probeer het opnieuw.
- **De HireData-marketplace verschijnt niet:** voer `codex plugin marketplace list` uit en herstart daarna de ChatGPT-desktop-app.
- **De plugin is geïnstalleerd, maar de skills verschijnen niet:** schakel HireData in bij **Plugins** en start een nieuw gesprek.
- **HireData vraagt je niet om in te loggen:** start een nieuw gesprek met de plugin ingeschakeld en doe een verzoek dat HireData-workspace-gegevens nodig heeft.
- **Je organisatie blokkeert de installatie:** vraag je ChatGPT- of Codex-beheerder om de HireData-marketplace en MCP-verbinding toe te staan.
- **De skills worden niet geactiveerd in Claude:** controleer of de plugin als geïnstalleerd wordt weergegeven (`/plugin` in Claude Code, of de plugin-browser in een Claude-organisatie) en start een nieuw gesprek.
- **Je hebt alleen de MCP-tools nodig of gebruikt een andere assistent:** volg de [handmatige MCP-verbindingshandleiding](/apps/mcp/connect-hiredata-to-your-ai-assistant).

## De plugin verwijderen

- **ChatGPT of Codex:** voer `codex plugin remove hiredata@hiredata-skills` uit.
- **Claude Code:** voer `/plugin uninstall hiredata@hiredata-skills` uit.
- **Claude Team en Enterprise:** verwijder de plugin via de plugin-browser, of vraag een Owner om de beschikbaarheid ervan te wijzigen in **Organization settings → Plugins**. Plugins die door een Owner op **Required** zijn ingesteld, kunnen niet door leden worden verwijderd.

Het verwijderen van de plugin trekt niet automatisch een bestaande HireData OAuth-autorisatie in. Verbreek de verbinding met HireData in je AI-assistent, of trek de autorisatie in vanuit je HireData-instellingen wanneer je ook de toegang wilt verwijderen.
