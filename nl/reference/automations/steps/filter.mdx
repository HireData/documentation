**Filter** beslist of de run doorgaat. Wanneer de condities slagen, gaat de run naar de volgende stap; wanneer ze niet slagen, stopt de run hier.

De drawer heeft de kop **Filter** met de tabbladen **Filters** en **Advanced**.

## Instellingen

- **Field**. Het **Select field**-vak. Typ om te zoeken: "2: Answer" vindt "Question 2: Answer". De lijst bevat de velden van het event en de outputs van eerdere stappen.
- **Operator**. Het **Select**-vak naast het veld. Uitgeschakeld tot er een veld is gekozen. De aangeboden operators hangen af van het type van het veld, hieronder opgesomd.
- **Value**. Een vak dat verschijnt voor operators die met iets vergelijken. **is empty** en **is not empty** hebben er geen.
- **Add Filter**. Voegt een rij toe aan dezelfde set.
- **Add New Set**. Begint een nieuwe set onder de eerste.
- **AND / OR**. Een toggle die tussen twee rijen verschijnt, en nog een die tussen twee sets verschijnt. Standaard **AND**. Binnen een set bepaalt deze of elke rij of een willekeurige rij moet slagen. Tussen sets bepaalt deze of elke set of een willekeurige set moet slagen.
- **Unique Constraints**. Op het tabblad **Advanced**. Kies velden, en het Filter slaagt slechts één keer voor elke combinatie van hun waarden. Met een identifier en een statusveld geselecteerd, slaagt een record voor een gegeven status één keer, hoeveel events het ook produceert met die status.

### Operators

| Veldtype | Operators |
| --- | --- |
| Tekst | equals, not equals, is empty, is not empty, contains, does not contain, starts with, ends with, does not start with, does not end with |
| Getal | equals, not equals, is empty, is not empty, greater than, less than, greater than or equal, less than or equal |

Velden die een bereik of een set waarden bevatten bieden ook **between**, **one of** en **not one of**.

## Wat het oplevert

Niets nieuws. De variabelen die na een Filter beschikbaar zijn, zijn dezelfde als ervoor.

Op de runpagina draagt een geslaagd Filter de regel "Completed" met de tijd. De timeline registreert "Filter: Run Moved", daarna "Filter: Completed" met elke set gemarkeerd als **Valid** en de waarde die het verwachtte tegenover de waarde die het vond.

## Wat de run stopt

Condities die niet slagen. De timeline registreert "Filter: Cancelled" met het bericht "Filter not passed." gevolgd door "Filter: Run Cancelled". Stappen na het Filter tonen geen statusregel, en in de runs-lijst toont de **Step**-kolom van de run "Filter".

<img src="/images/automations/38-filter-cancelled-timeline.png" alt="Een run timeline met Run Scheduled, Run Started, Run Moved, daarna Filter: Cancelled met het bericht Filter not passed. en Filter: Run Cancelled" width="384" />

Een Filter binnen een Split stopt alleen zijn eigen branch. Zie [Split](/nl/reference/automations/steps/split).

Andere redenen waarom een run kan stoppen staan in [Redenen voor run-annuleringen](/nl/knowledge-base/run-cancellation-reasons).

## Patronen

- **Bewaak de start.** Een Filter als eerste stap stopt runs die de start zelf niet kan uitsluiten, zoals een reactie met een leeg antwoord op de vraag die ertoe doet.
- **Controleer opnieuw na een wachttijd.** Een Delay en dan een Filter bevestigt dat het record nog steeds kwalificeert zodra het wachten voorbij is. Een kandidaat die intussen is geplaatst krijgt de follow-up nooit.
- **Eén keer per status.** Een unique constraint op het id van het record en het statusveld ervan laat een statuswijziging één keer door, ook wanneer de app dezelfde update meer dan eens verstuurt.
- **Kies Split voor twee uitkomsten.** Een Filter beëindigt de run bij een nee. Wanneer zowel ja als nee stappen nodig hebben, gebruik dan een [Split](/nl/reference/automations/steps/split) met een Filter-branch voor elk.

## Veelgemaakte fouten

- **Een rij opslaan zonder operator.** De drawer slaat hem op en het canvas toont de ruwe key `enums.conditions.undefined` op de plek van de operator. Open het Filter opnieuw en kies er een.
- **Alleen op nummer zoeken.** "Question 2" matcht ook "Question 12". Typ ook een deel van de titel van de vraag.
- **Een overgeslagen stap verwachten.** Een Filter dat niet slaagt annuleert de run, het springt niet naar de volgende stap.
- **AND en OR mengen zonder sets.** Rijen in één set delen één toggle. Om "A en B" te combineren met "C", zet je A en B in één set, C in een andere, en zet je de toggle tussen de sets op **OR**.
