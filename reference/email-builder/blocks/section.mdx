A section is a band across the email. It holds the blocks a recipient reads, and it carries the background, the padding, and the border behind them. Every block in an email sits in one.

Section is the only block you add from the **Template** panel. Open **Blocks** there and press **+** on any row. No menu opens, because a section is the only thing a Template takes. No section's own menu offers a Section either, so sections never nest.

## Settings

- **Background color** fills the band. It starts on the brand's surface colour, which the control names rather than showing as a hex code.
- **Background image** takes a picture from the media library through **Choose image**, and it sits behind the whole band. The same picker offers the variables that carry an image, so the background can follow the brand.
- **Blocks** lists what the section holds, in order. **+** opens the menu of blocks you can add, **−** deletes a row, and the handle on the left drags it.
- **Spacing** holds three controls. **Margin** is the gap outside the band, **None**, **Normal**, **Large**, or **Custom** for a top and bottom value in pixels. **Padding** is the gap inside it, with the same four choices and a box per side. **Width** sets how wide the blocks inside the section run: **Default**, **Large**, **Full**, or **Custom**, which opens a slider from 640 to 1240 pixels.
- **Border** holds **Border color**, **Border width**, and **Border radius**, each on the same **None** / **Normal** / **Large** / **Custom** pattern.

## How it renders

The email body is 600 pixels wide. A section fills that width edge to edge, and its blocks sit in a column inside the padding you set.

A section with several blocks renders as a stack of rows that share one background. The border and the rounded corners belong to the section rather than to any row, so the top border and the top corners land on the first block, the bottom border and the bottom corners on the last, and the rows in between run straight.
