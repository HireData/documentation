An Image block puts a picture in the email. Add it from the **Blocks** menu of a section or a column.

## How it renders

The image goes into the email as a plain picture, sized by **Width** and **Height** and aligned by **Alignment**.

![An image block at Full width in a rendered email, filling the section from edge to edge under a line of body text](/images/email-builder/blocks/06c-image-rendered.png)

Inside a column it ignores **Width** and takes the width of the column instead, so a picture in a 40 per cent column comes out at 40 per cent of the section. That is what makes a picture beside a paragraph line up.

The block sets no maximum for the file size or the pixel dimensions of what you pick. A photograph straight off a phone goes out at its full weight, so scale it down before you upload it.

## Settings

- **Image** opens the media library, with **Upload media** for a new file and two tabs for what is already there. **Fields** lists the variables that carry an image, such as a brand logo or a sender avatar. Pick one of those and the picture changes with whoever the email is about.
- **Width** is **Auto**, which keeps the picture at its own size, or **Full**, which stretches it to fill whatever holds it.
- **Alignment** is left, centre, or right, and does nothing at **Full** width.
- **Height** is **Auto**, **Full**, or **Custom**, which opens a slider from 10 to 300 pixels.
- **Border radius** rounds the corners: **None**, **Normal**, **Large**, or **Custom** for a value per corner.

<img src="/images/email-builder/blocks/06-image-settings.png" alt="The Image settings panel showing the chosen picture, Width set to Auto, Alignment, Height set to Auto, and Border radius" width="384" />

Alt text is not on this panel. It belongs to the picture, so you set it in the media library: open **Image**, click the picture, and fill in **Alt text** on the card that opens. It falls back to the image title when you leave it empty, which is why a picture named "Brand: Banner" is worth naming better than "image-3-final".

<img src="/images/email-builder/blocks/06b-image-alt-text.png" alt="The media library card for an image, with a Title reading Brand: Banner, an empty Alt text box, and a note saying it falls back to the image title if left empty" width="464" />

Write alt text that says what the picture is for, not what it looks like. A recipient whose client blocks images sees that line instead of the picture, and blocked images are the normal case rather than the exception.
