Das HireData-Plugin kombiniert wiederverwendbare Recruiting-Workflows mit der offiziellen MCP-Verbindung von HireData. Es hilft ChatGPT, Codex und Claude dabei, HireData-Automatisierungen zu planen, zu erstellen, zu testen und zu verbessern, anstatt ihnen Tools ohne die zugehörige Arbeitsweise zur Verfügung zu stellen.

<Note>
  Das Plugin ist derzeit als Early-Access-Installation über den öffentlichen GitHub-Marketplace von HireData verfügbar. Es erscheint noch nicht im universellen Plugin-Verzeichnis von OpenAI. Verwenden Sie diese Schritte mit der ChatGPT-Desktop-App, der Codex-CLI, Claude Code oder einer Claude Team-/Enterprise-Organisation. Für Gemini oder eine reine MCP-Verbindung folgen Sie der Anleitung [HireData mit Ihrem KI-Assistenten verbinden](/apps/mcp/connect-hiredata-to-your-ai-assistant).
</Note>

## Was das Plugin hinzufügt

Die erste Version enthält fünf Skills:

- **Plan an activation** – Kundenprobleme mit wirkungsvollen HireData-Workflows und messbaren Ergebnissen verknüpfen.
- **Create triggers** – das richtige Ereignis, den passenden Zeitpunkt, Filter und Beziehungen wählen, bevor ein Trigger erstellt wird.
- **Create forms** – prägnante Formulare mit Validierung, Verzweigung und einem klaren nächsten Schritt gestalten.
- **Create email templates** – Variablen, Modifikatoren und begrenzte KI-Variablen sicher einsetzen.
- **Create WhatsApp templates** – prägnante, kontextbezogene Vorlagen entwerfen, mit passender Begründung der Kategorie und Folgepfaden.

Das Plugin konfiguriert außerdem die bestehende Remote-Verbindung zum HireData MCP unter `https://api.hiredata.com/mcp`. Es bündelt oder deployt keinen separaten MCP-Server.

| Installation | Was Sie erhalten | Wann sinnvoll |
| --- | --- | --- |
| HireData-Plugin | Fünf HireData-Skills und die MCP-Verbindung | Sie nutzen ChatGPT Desktop, Codex oder Claude und möchten sowohl das HireData-Wissen als auch die Tools |
| Nur MCP | Live-HireData-Tools ohne die fünf Skills | Sie nutzen Gemini, einen anderen MCP-Client, einen individuellen Claude-Plan ohne Organisationskatalog oder benötigen nur den Zugriff auf die Tools |

## Bevor Sie beginnen

Sie benötigen:

- Ein HireData-Konto mit Zugriff auf mindestens einen Workspace.
- Für ChatGPT oder Codex: eine aktuelle ChatGPT-Desktop-App oder Codex-CLI mit Unterstützung für `codex plugin`.
- Für Claude: Claude Code oder eine Claude Team-/Enterprise-Organisation mit aktivierten Cowork- und Skills-Funktionen.
- Berechtigung zum Hinzufügen von Git-Marketplaces und MCP-Verbindungen. Der KI-Administrator Ihrer Organisation kann diese Funktionen einschränken.

## Plugin in ChatGPT oder Codex installieren

<Steps>
  <Step title="HireData-Marketplace hinzufügen">
    Öffnen Sie ein Terminal und führen Sie Folgendes aus:

    ```bash
    codex plugin marketplace add HireData/skills
    ```

    Damit wird das öffentliche GitHub-Repository von HireData als Marketplace `hiredata-skills` hinzugefügt. Sie müssen das Repository nicht klonen.
  </Step>
  <Step title="HireData installieren">
    Führen Sie aus:

    ```bash
    codex plugin add hiredata@hiredata-skills
    ```

    Folgen Sie eventuellen Einrichtungshinweisen von Codex. Der Quellcode des Plugins ist öffentlich unter [github.com/HireData/skills](https://github.com/HireData/skills) verfügbar.
  </Step>
  <Step title="Plugin neu laden">
    Starten Sie eine neue Codex-Sitzung. Wenn Sie die ChatGPT-Desktop-App verwenden, starten Sie diese neu, öffnen Sie **Plugins** und prüfen Sie, ob **HireData** unter **Installed** oder im Marketplace **HireData Skills** erscheint.

    Installierte Skills und Tools werden geladen, sobald Sie eine neue Konversation starten. In einer bestehenden Konversation erscheinen sie nicht nachträglich.
  </Step>
  <Step title="HireData-Konto verbinden">
    Melden Sie sich bei der Aufforderung bei HireData an. Wählen Sie den bzw. die Workspaces aus, auf die der Assistent zugreifen darf, prüfen Sie die angeforderten Berechtigungen und klicken Sie auf **Authorize**.

    Der Assistent erhält nur den Workspace-Zugriff, den Sie auswählen, und arbeitet mit Ihren bestehenden HireData-Berechtigungen. Siehe [wie Zugriff und Sicherheit in HireData funktionieren](/apps/mcp/connect-hiredata-to-your-ai-assistant#how-access-and-security-work).
  </Step>
  <Step title="Installation überprüfen">
    Prüfen Sie das installierte Plugin im Terminal:

    ```bash
    codex plugin list --marketplace hiredata-skills
    ```

    Probieren Sie anschließend eine dieser Anfragen in einer neuen Konversation aus:

    - „Nutze HireData, um unsere vorhandenen Vorlagen zu überprüfen und den wirkungsvollsten fehlenden Workflow zu bewerten. Erstelle noch nichts."
    - „Nutze HireData, um eine Bestätigungs-E-Mail für Bewerbungen zu entwerfen, die eine KI-Variable sicher verwendet. Zeige mir eine Vorschau und sende sie nicht."
    - „Nutze HireData, um ein Formular zur Verfügbarkeit von Kandidaten zu erstellen. Zeige mir das Formular und die Verzweigungslogik, bevor du es anlegst."
  </Step>
</Steps>

## Plugin in Claude installieren

Bei der Installation des Plugins wird gleichzeitig die HireData-MCP-Verbindung konfiguriert. Eine separate Einrichtung des Connectors ist daher nicht erforderlich.

### Claude Code

Führen Sie diese Befehle innerhalb von Claude Code aus:

```bash
/plugin marketplace add HireData/skills
/plugin install hiredata@hiredata-skills
```

Melden Sie sich bei der ersten Nutzung bei HireData an, wählen Sie die zulässigen Workspaces aus und autorisieren Sie den Zugriff. Starten Sie vor dem Testen eine neue Konversation; die Skills sind unter Namensräumen wie `/hiredata:hiredata-plan-activation` und so weiter verfügbar.

### Claude Team und Enterprise (Web, Desktop und Cowork)

Ein Organisationsinhaber verteilt das Plugin über den Organisationskatalog:

<Steps>
  <Step title="Marketplace hinzufügen">
    Öffnen Sie **Organization settings → Plugins** und fügen Sie einen mit GitHub synchronisierten Marketplace mit dem Repository `HireData/skills` hinzu. Die erste Synchronisierung erfolgt automatisch, und spätere Plugin-Releases werden aus dem Default-Branch des Repositorys synchronisiert.

    Alternativ können Sie einen benutzerdefinierten Marketplace hinzufügen und das Plugin als ZIP-Datei hochladen (das Verzeichnis `plugins/hiredata` aus dem Repository). Nutzen Sie diese Option, wenn Ihre Organisation die Synchronisierung mit GitHub nicht bevorzugt; beachten Sie, dass manuelle Uploads keine automatischen Aktualisierungen erhalten.
  </Step>
  <Step title="Plugin verfügbar machen">
    Legen Sie die Installations-Einstellung des HireData-Plugins fest, zum Beispiel **Available for install** oder **Installed by default**.
  </Step>
  <Step title="Als Mitglied installieren">
    Mitglieder öffnen den Plugin-Browser über die Chat-Oberfläche, installieren **HireData** und schließen bei der ersten Nutzung die HireData-Anmeldung ab. Das Plugin funktioniert anschließend im Claude-Web-Chat, in der Claude-Desktop-App und in Cowork-Sitzungen. Wenn der Owner das Plugin auf **Installed by default** gesetzt hat, überspringen Mitglieder diesen Schritt vollständig.
  </Step>
</Steps>

Individuelle Claude-Pläne ohne Organisationskatalog können [die Skills mit einem Prompt installieren](#install-the-skills-with-a-prompt) und mit der [manuellen MCP-Verbindung](/apps/mcp/connect-hiredata-to-your-ai-assistant) kombinieren.

## Install the skills with a prompt

Keine Plugin-Unterstützung in Ihrem Plan oder Assistenten? Die Skills sind einfache, öffentliche Dateien – Sie können Ihren KI-Assistenten sie also selbst herunterladen und für Sie verpacken lassen.

### Claude (Chat, Desktop und Cowork)

Kopieren Sie diesen Prompt in eine Claude-Konversation, die Dateien erstellen kann (zum Beispiel eine Cowork-Sitzung):

```text
Download the five HireData skills from https://github.com/HireData/skills
(they are in plugins/hiredata/skills). Package each skill as a separate
.skill file — a ZIP with that skill's SKILL.md and references folder at
its root — and send me the five files so I can save them as skills on my
account.
```

Speichern Sie jede von Claude gelieferte Datei als Skill in Ihrem Konto. In Kombination mit dem [HireData MCP-Connector](/apps/mcp/connect-hiredata-to-your-ai-assistant) erhalten Sie damit dasselbe Verhalten wie mit dem vollständigen Plugin. Wenn Ihre Organisation das Speichern von Skills nicht erlaubt, bitten Sie einen Owner, das Plugin stattdessen über den Organisationskatalog zu verteilen.

### Jeder andere Assistent

Assistenten ohne installierbare Skills können einem Skill dennoch für eine einzelne Aufgabe folgen. Ersetzen Sie den Skill-Namen und Ihr Ziel in diesem Prompt:

```text
Fetch https://raw.githubusercontent.com/HireData/skills/main/plugins/hiredata/skills/hiredata-plan-activation/SKILL.md,
follow the workflow it describes (fetch the files it references too), and
help me with: [your goal]
```

Das funktioniert in ChatGPT, Gemini, Microsoft Copilot oder jedem Assistenten, der öffentliche Webseiten lesen kann, und lässt sich gut mit der [manuellen MCP-Verbindung](/apps/mcp/connect-hiredata-to-your-ai-assistant) kombinieren. Die fünf Ordnernamen sind `hiredata-plan-activation`, `hiredata-create-triggers`, `hiredata-create-forms`, `hiredata-create-email-templates` und `hiredata-create-whatsapp-templates`.

## Plugin aktualisieren

- **ChatGPT oder Codex:** Führen Sie `codex plugin marketplace upgrade hiredata-skills` aus und öffnen Sie anschließend **Plugins** oder führen Sie `/plugins` in der Codex-CLI aus, um das Update anzuwenden.
- **Claude Code:** Führen Sie `/plugin marketplace update hiredata-skills` aus.
- **Claude Team und Enterprise:** Mit GitHub synchronisierte Marketplaces werden automatisch aktualisiert, wenn HireData eine neue Plugin-Version veröffentlicht. Manuell hochgeladene ZIPs erfordern einen erneuten Upload.

Starten Sie nach dem Update eine neue Konversation, damit Ihr Assistent die neuen Skills und die neue Konfiguration lädt.

## Fehlerbehebung

- **Der Befehl `codex plugin` ist nicht verfügbar:** Aktualisieren Sie Codex oder die ChatGPT-Desktop-App und versuchen Sie es erneut.
- **Der HireData-Marketplace erscheint nicht:** Führen Sie `codex plugin marketplace list` aus und starten Sie die ChatGPT-Desktop-App neu.
- **Das Plugin ist installiert, aber die Skills erscheinen nicht:** Aktivieren Sie HireData unter **Plugins** und starten Sie eine neue Konversation.
- **HireData fordert Sie nicht zur Anmeldung auf:** Starten Sie eine neue Konversation mit aktiviertem Plugin und stellen Sie eine Anfrage, die HireData-Workspace-Daten benötigt.
- **Ihre Organisation blockiert die Installation:** Bitten Sie Ihren ChatGPT- oder Codex-Administrator, den HireData-Marketplace und die MCP-Verbindung freizugeben.
- **Die Skills werden in Claude nicht ausgelöst:** Prüfen Sie, ob das Plugin als installiert angezeigt wird (`/plugin` in Claude Code oder der Plugin-Browser in einer Claude-Organisation), und starten Sie eine neue Konversation.
- **Sie benötigen nur die MCP-Tools oder nutzen einen anderen Assistenten:** Folgen Sie der [Anleitung zur manuellen MCP-Verbindung](/apps/mcp/connect-hiredata-to-your-ai-assistant).

## Plugin entfernen

- **ChatGPT oder Codex:** Führen Sie `codex plugin remove hiredata@hiredata-skills` aus.
- **Claude Code:** Führen Sie `/plugin uninstall hiredata@hiredata-skills` aus.
- **Claude Team und Enterprise:** Entfernen Sie das Plugin über den Plugin-Browser oder bitten Sie einen Owner, dessen Verfügbarkeit in **Organization settings → Plugins** zu ändern. Von einem Owner als **Required** markierte Plugins können von Mitgliedern nicht entfernt werden.

Das Entfernen des Plugins widerruft nicht zwangsläufig eine bestehende HireData-OAuth-Freigabe. Trennen Sie HireData in Ihrem KI-Assistenten oder widerrufen Sie die Freigabe in den HireData-Einstellungen, wenn Sie auch den Zugriff entfernen möchten.
