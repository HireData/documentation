_Jedes Bild in einer HireData-E-Mail kommt aus der **Media Library**: Ihr Logo, ein Header-Foto, ein Hintergrund oder die kleinen Social-Icons in Ihrer Signatur. Sie öffnen die Media Library aus jedem Bildfeld im E-Mail-Editor, laden Ihre Datei einmal hoch und verwenden sie in jeder Vorlage wieder. Jedes Bild erhält außerdem eine eigene öffentliche URL – genau das, was Sie brauchen, wenn eine Signatur oder ein Block nach einem Bild-Link fragt._

## Schritt 1: Die Media Library öffnen

Öffnen Sie eine E-Mail-Vorlage unter **Settings** \> **Emails** und klicken Sie dann auf ein beliebiges Bildfeld im Editor. Wählen Sie eine Section aus, und ihr Panel enthält **Background image** mit einer **Choose image**-Schaltfläche; ein Bildblock oder ein Signaturbild öffnet dieselbe Library.

<img src="/images/media-library/01-choose-image.png" alt="Das Section-Einstellungs-Panel mit Background color über einem Background-image-Feld mit einer Choose-image-Schaltfläche" width="384" />

Die Media Library öffnet sich als Pop-up mit zwei Tabs.

- **Home** sind die in Ihrem Workspace gespeicherten Medien, einschließlich allem, was Sie oder eine Kollegin bzw. ein Kollege hochlädt. Der Tab zeigt die Anzahl der Elemente, mit **Show** und den Seitenzahlen unten, um eine lange Library durchzugehen.
- **Fields** sind die Bilder, die aus einer Variable kommen, etwa Avatar, Banner und Logo Ihrer Marke sowie das Foto des Absenders. Diese bleiben dynamisch: Sie folgen der Marke bzw. dem Absender, den die Automatisierung beim Senden der E-Mail verwendet.

![Der Kopfbereich des Media-Library-Pop-ups mit den Tabs Home und Fields, einem Suchfeld, einer Upload-media-Schaltfläche und einer Anzeige mit 42 Elementen](/images/media-library/02-media-library.png)

## Schritt 2: Ihr Bild hochladen

Klicken Sie oben rechts in der Media Library auf **Upload media** und wählen Sie die Datei von Ihrem Gerät aus. Das Bild erscheint sofort im Raster und bleibt für jede andere Vorlage in Ihrem Workspace verfügbar – Sie laden jedes Logo oder Icon also nur einmal hoch.

<Tip>
  **Welche Datei Sie hochladen sollten:**

  - Verwenden Sie **PNG mit transparentem Hintergrund** für Logos und Icons, damit sie auf jeder Hintergrundfarbe richtig aussehen.
  - Wählen Sie eine **dunkle Version** Ihres Logos — die meisten E-Mail-Clients verwenden einen weißen Hintergrund, auf dem ein helles Logo verschwindet.
  - Laden Sie Icons in etwa der **doppelten Größe** hoch, in der sie angezeigt werden sollen (zum Beispiel 64 x 64 px für ein 32-px-Signatur-Icon), damit sie auf hochauflösenden Bildschirmen scharf bleiben.
  - Halten Sie die Dateien klein (unter ein paar hundert KB). Schwere Bilder verlangsamen die E-Mail und können der Zustellbarkeit schaden.
</Tip>

## Schritt 3: Titel und Alt-Text hinzufügen

Klicken Sie auf ein Bild im Raster, um rechts seine Details zu öffnen.

- **Title** — der Name, über den Sie und Ihre Kolleginnen und Kollegen das Bild wiederfinden. Ein Upload kommt mit dem Dateinamen an, `image.png` lohnt sich also umzubenennen.
- **Alt text** — der Text, der angezeigt wird, wenn das Bild nicht geladen werden kann, und der Text, den ein Screenreader vorliest. Lassen Sie ihn leer, greift HireData auf den Bildtitel zurück.

Unter **More info** finden Sie die **Id** und den **Mime type** des Bildes.

<img src="/images/media-library/03-image-details.png" alt="Die Detailkarte eines hochgeladenen Bildes, mit den Teilen- und Schließen-Schaltflächen neben dem Titel, den Tabs Description und More info, einem Title mit dem Wert image.png und einem leeren Alt-text-Feld mit dem Hinweis, dass es auf den Bildtitel zurückfällt" width="448" />

<Warning>
  Beide Felder sind im **Fields**-Tab schreibgeschützt. Ein Bild, das aus einer Variable kommt, übernimmt Titel und Alt-Text aus der Variable — einem so bezogenen Bild kann also kein eigener Alt-Text gegeben werden. Das geht nur bei einem Upload im **Home**-Tab.
</Warning>

<Note>
  Viele Empfänger blockieren Bilder standardmäßig, und manche Firmen-Mail-Clients laden sie nie. Der Alt-Text ist das, was sie stattdessen sehen – schreiben Sie also etwas Aussagekräftiges: „HireData-Logo" statt „image1".
</Note>

## Schritt 4: Das Bild in Ihrer E-Mail verwenden

Klicken Sie bei ausgewähltem Bild unten im Detail-Panel auf **Add media to field**. Das Bild wird in das Feld eingefügt, aus dem Sie die Media Library geöffnet haben, und das Pop-up schließt sich.

Speichern Sie die Vorlage und prüfen Sie über die Vorschau oder eine Test-E-Mail, wie das Bild dargestellt wird, bevor Sie die Vorlage in einer Automatisierung verwenden.

## Schritt 5: Die Bild-URL kopieren (für Signatur-Icons)

An manchen Stellen wird statt einer Datei ein Bild-**Link** verlangt — Social-Icons in einer Signatur sind das übliche Beispiel. Jedes Bild in der Media Library hat eine eigene öffentliche URL:

1. Öffnen Sie das Bild in der Media Library.
2. Klicken Sie auf das **Teilen**-Symbol oben rechts im Detail-Panel.
3. Eine **URL Copied**-Bestätigung erscheint. Der Link befindet sich jetzt in Ihrer Zwischenablage, und mit **Open URL** können Sie ihn in einem neuen Tab prüfen.
4. Fügen Sie den Link überall dort ein, wo nach der Bild-URL gefragt wird.

![Die URL-Copied-Benachrichtigung mit einer Open-URL-Schaltfläche daneben](/images/media-library/04-url-copied.png)

<Warning>
  Diese URL ist öffentlich: Jeder, der den Link hat, kann das Bild öffnen. Laden Sie nur Bilder hoch, die bedenkenlos im offenen Internet stehen dürfen — keine Kandidatendokumente, Ausweis-Scans oder andere vertrauliche Inhalte.
</Warning>

## Icons in Ihrer E-Mail-Signatur

Ihre Signatur ist Teil der E-Mail-Vorlage, daher funktionieren Signaturbilder genauso wie jedes andere Bild:

1. Laden Sie die gewünschten Icons (zum Beispiel LinkedIn, Instagram oder ein Zertifizierungs-Badge) über **Upload media** hoch.
2. Klicken Sie im E-Mail-Editor auf den Signaturblock und wählen Sie das Bildelement aus, das Sie befüllen möchten.
3. Wählen Sie das Icon aus der Media Library und klicken Sie auf **Add media to field**, oder fügen Sie die Bild-URL ein, wenn das Element nach einem Link fragt.

<Tip>
  Beschränken Sie Signatur-Icons auf maximal drei oder vier, alle in derselben Größe, und geben Sie jedem einen Alt-Text („LinkedIn"). Eine Signatur voller Bilder sieht für Spamfilter wie ein Newsletter aus.
</Tip>

<Note>
  **Logo**, **Banner** und **Avatar** Ihrer Marke gehören nicht als hochgeladene Bilder in die Signatur — legen Sie sie einmal unter **Settings** \> **Brands** fest, und jede Vorlage, die diese Marke verwendet, übernimmt sie automatisch. Siehe [Marken](/de/settings/brands).
</Note>

## Gut zu wissen

- Die Media Library wird im gesamten Workspace geteilt: Ein Bild, das eine Kollegin oder ein Kollege hochlädt, steht allen zur Verfügung, die Vorlagen erstellen.
- Bilder, die Sie über den **Fields**-Tab hinzufügen (Marken-Avatar, Banner, Logo, Absenderfoto), bleiben dynamisch. Ändern Sie das Logo unter **Settings** \> **Brands**, und jede E-Mail, die diese Marke verwendet, wird automatisch aktualisiert — die Vorlagen müssen nicht angefasst werden.
- Senden Sie sich immer eine Test-E-Mail, bevor Sie eine Vorlage live schalten. Die Bilddarstellung unterscheidet sich zwischen Outlook, Gmail und Apple Mail.
