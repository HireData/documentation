Multiple Choice und Dropdown sind ein Feldtyp mit einem Umschalter dazwischen. Multiple Choice listet jede Option auf dem Bildschirm auf, sodass die befragte Person alle auf einmal sieht. Dropdown legt sie hinter ein Menü, was die bessere Form ist, sobald die Liste lang wird.

Beide befinden sich in der Gruppe **Choice** der **Add Content**-Palette. Die Schaltfläche unten links auf der Karte wechselt zwischen beiden.

## Einstellungen

Die Karte enthält die [Einstellungen, die alle Felder gemeinsam haben](/de/reference/forms/overview#settings-every-field-shares). Die Optionen selbst und drei weitere Einstellungen gehören zu diesem Typ.

- **Options**, die Liste, aus der die befragte Person wählt.
- **Add Data Source**, über der Liste, füllt die Optionen aus einer gespeicherten Liste, die Ihr Workspace bereits führt, statt aus Optionen, die Sie eintippen. Siehe [Datenquellen](/de/reference/forms/data-sources).
- **Conversational Button Text**, die Beschriftung der Schaltfläche, die die Liste in einer WhatsApp-Konversation öffnet. Das Feld zeigt „Choose" als Platzhalter.
- **Placeholder**, nur bei Dropdown, der Text im geschlossenen Menü, bevor etwas gewählt wurde.
- Die Fußzeilen-Schaltfläche **Single Answer** öffnet **Answer selection**, das einen Schalter enthält, **Allow multiple answers**. Schalten Sie ihn ein, und die befragte Person kann mehr als eine Option wählen.

Jede Optionszeile hat den Optionstext, ein Zahnrad, ein Plus und ein Minus. Das Zahnrad öffnet die **Auto reply (on answer)** dieser Option, die WhatsApp-Nachricht, die gesendet wird, wenn diese Option gewählt wird. Das Plus fügt darunter eine Zeile hinzu, das Minus entfernt eine. Ein Auswahlfeld braucht zwei Optionen, deshalb verschwindet das Minus, sobald nur noch zwei übrig sind.

## Was gespeichert wird

Die gewählten Optionen, als Liste. Ein Feld mit einer einzigen Antwort speichert eine Liste mit einem Eintrag.

## Logik-Operatoren

| Operator | Trifft zu, wenn |
|---|---|
| has response | die befragte Person überhaupt etwas gewählt hat |
| is equal to | die Antwort die von Ihnen gewählte Option ist |
| is not equal to | die Antwort irgendeine andere Option ist |
| is one of | die Antwort eine der von Ihnen gewählten Optionen ist |
| is not one of | die Antwort keine der von Ihnen gewählten Optionen ist |

**is one of** ist der Operator, der Regeln spart. Drei Optionen, die alle zur selben Folgefrage führen, brauchen eine Regel, nicht drei.

## Evaluation

Schalten Sie **Criteria**, **Scoring** oder **Skills** für das Formular im [Evaluation-Tab](/de/reference/forms/evaluation/overview) ein, und jeder davon erhält einen Schalter auf dieser Karte.

Ein Auswahlfeld lässt sich am leichtesten bewerten, weil Sie bereits jede mögliche Antwort kennen. Punkte pro Option ist eine Regel, die Sie einmal schreiben und der Sie vertrauen können.
