File Upload gibt der befragten Person einen Ablagebereich mit **Drop Files Here** und darunter „Click here or drop files to upload them". So sammelt ein Formular einen Lebenslauf, ein Zertifikat oder ein Portfolio ein.

Es befindet sich in der Gruppe **Other** der **Add Content**-Palette.

## Einstellungen

Die Karte enthält die [Einstellungen, die alle Felder gemeinsam haben](/de/reference/forms/overview#settings-every-field-shares). File Upload ergänzt zwei eigene.

- **Multiple**, **Yes** oder **No**, entscheidet, ob die befragte Person mehr als eine Datei anhängen kann.
- **File type**, eine Voreinstellung aus **Any**, **Image**, **Audio**, **Video**, **Media**, **PDF**, **Document**, **Powerpoint**, **Word Document**, **Sheet** und **Archive**.

**File type** ist eine Voreinstellung, keine Liste, die Sie selbst schreiben. Ein Formular, das ein PDF oder ein Word-Dokument möchte, muss also **Document** akzeptieren und es später aussortieren. Ein Größenlimit lässt sich nicht festlegen.

Der Wortlaut des Ablagebereichs ist übersetzbar. Er steht unter **Settings** in [Sprachen und Übersetzungen](/de/reference/forms/overview#localization), als **Upload title** und **Upload description**.

## Was gespeichert wird

Die hochgeladenen Dateien, mit Dateiname und Typ jeder einzelnen.

## Logik-Operatoren

Die Operator-Auswahl ist fest auf **has response** gestellt und kann nicht geändert werden. Eine Regel kann fragen, ob die befragte Person überhaupt etwas angehängt hat – genug, um jemanden ohne Lebenslauf woandershin zu schicken.

![Eine Bedingung auf einer File-Upload-Frage im Logic-Tab, mit dem Operator has response und ohne Wertefeld daneben](/images/forms-builder/fields/operators-file-upload.png)

## Evaluation

Schalten Sie **Criteria**, **Scoring** oder **Skills** für das Formular im [Evaluation-Tab](/de/reference/forms/evaluation/overview) ein, und jeder davon erhält einen Schalter auf dieser Karte.
