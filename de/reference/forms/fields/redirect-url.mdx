Redirect URL ist ein Ending ohne Bildschirm. Die befragte Person erreicht es, und der Browser schickt sie zu der Adresse, die Sie festgelegt haben. Die Builder-Vorschau sagt es unverblümt: „This field redirects the user automatically and won't have a display."

Verwenden Sie es, um jemanden nach dem Formular an eine Buchungsseite, eine Jobbörse oder Ihre eigene Website zu übergeben.

Wie das andere Ending steht es in der **Endings**-Gruppe am Ende der Feldliste des **Content**-Tabs. Es befindet sich in der Gruppe **Ending** der **Add Content**-Palette, und die Schaltfläche unten links auf der Karte schaltet es auf einen [Ending Screen](/de/reference/forms/fields/ending-screen) um.

## Einstellungen

Eine, und sie ist das ganze Feld.

- **Redirect URL**, bis zu 255 Zeichen, die Adresse, zu der die befragte Person geschickt wird.

Es gibt keinen Titel, keine Beschreibung, kein Bild und keine Schaltfläche, weil die befragte Person das Feld nie sieht. Wenn sie vor dem Weitergehen etwas lesen soll, verwenden Sie stattdessen einen [Ending Screen](/de/reference/forms/fields/ending-screen) mit eingeschaltetem **Button** und **Redirect timer**.

![Eine Redirect-URL-Karte mit einem einzelnen Redirect-URL-Feld und einer Fußzeile mit Redirect URL, neben einer Vorschau mit dem Hinweis, dass das Feld automatisch weiterleitet und keine Anzeige hat](/images/forms-builder/fields/15-redirect-url.png)

## Was gespeichert wird

Nichts.

## Logik-Operatoren

Keine. Ein Ending hat keine **Add Rule**-Schaltfläche im **Logic**-Tab. Richten Sie eine Regel auf einer Frage auf dieses Ending, um jemanden hierher zu schicken.

![Der Logic-Tab mit einer Ending-Zeile ohne Add-Rule-Schaltfläche, neben einer Fragezeile, die eine hat](/images/forms-builder/fields/operators-endings.png)

## Evaluation

Eine Redirect URL trägt keine Evaluator-Schalter.
