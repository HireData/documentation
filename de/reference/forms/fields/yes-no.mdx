Yes/No stellt eine Frage mit zwei Antworten. **Checkbox** zeigt ein Kästchen, das die befragte Person ankreuzt. **Toggle** zeigt einen Schalter, den sie umlegt. Beide verhalten sich gleich und speichern denselben Wert, wählen Sie also die Variante, die zur Frage passt.

Es befindet sich in der Gruppe **Choice** der **Add Content**-Palette. Die Schaltfläche unten links auf der Karte wechselt zwischen beiden.

## Einstellungen

Die Karte enthält die [Einstellungen, die alle Felder gemeinsam haben](/de/reference/forms/overview#settings-every-field-shares), mit einem Unterschied. Statt der einzelnen **Auto reply (on answer)**, die die meisten Typen haben, gibt Yes/No jeder Antwort ihre eigene WhatsApp-Nachricht.

- **Auto reply (Yes)**, gesendet, wenn die Antwort Yes ist.
- **Auto reply (No)**, gesendet, wenn die Antwort No ist.

Sonst gibt es nichts einzustellen. Sie können die beiden Antworten nicht umbenennen. Wenn Sie eigene Formulierungen brauchen, etwa „Vollständiger Führerschein" gegenüber „Führerschein auf Probe", verwenden Sie [Multiple Choice](/de/reference/forms/fields/multiple-choice-and-dropdown) mit zwei Optionen.

## Was gespeichert wird

Yes oder No.

## Logik-Operatoren

| Operator | Trifft zu, wenn |
|---|---|
| has response | die befragte Person überhaupt geantwortet hat |
| is equal to | die Antwort der in der Regel gewählten entspricht |
| is not equal to | die Antwort die andere ist |

![Der Logic-Tab mit geöffneter Operator-Auswahl auf einer Yes/No-Bedingung, mit has response, is equal to und is not equal to, mit dem Wertefeld daneben auf Yes](/images/forms-builder/fields/operators-yes-no.png)

<Warning>
  Machen Sie ein Yes/No-Feld nicht zur Pflichtfrage. Eine befragte Person, die mit No antwortet, kommt nicht daran vorbei. **Next** tut nichts, keine Meldung erscheint, und keine Regel auf dem Feld löst je aus. Lassen Sie das Feld optional, bis der Fix ausgeliefert ist.
</Warning>

## Evaluation

Schalten Sie **Criteria**, **Scoring** oder **Skills** für das Formular im [Evaluation-Tab](/de/reference/forms/evaluation/overview) ein, und jeder davon erhält einen Schalter auf dieser Karte.

Yes/No ist das sauberste Feld, an dem Sie ein **Criteria**-Must-have aufhängen können, weil die Antwort einer von zwei bekannten Werten ist und keine Interpretation braucht. „Haben Sie einen Führerschein?" ist entweder erfüllt oder nicht.
