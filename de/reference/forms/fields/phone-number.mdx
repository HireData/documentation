Phone Number ist ein einzeiliges Feld für eine Telefonnummer. Die befragte Person sieht ein Hörer-Symbol im leeren Feld.

Es befindet sich in der Gruppe **Contact Info** der **Add Content**-Palette.

## Einstellungen

Die Karte enthält die [Einstellungen, die alle Felder gemeinsam haben](/de/reference/forms/overview#settings-every-field-shares). Phone Number ergänzt dieselben vier wie ein Textfeld.

- **Placeholder**, bis zu 255 Zeichen, angezeigt im leeren Feld.
- **Minimum Length** und **Maximum Length**, gezählt in Zeichen.
- **Validation Pattern**, ein regulärer Ausdruck, dem die Antwort entsprechen muss.

Es gibt keine telefonspezifische Validierungsmeldung, deshalb ist **Validation Pattern** der Weg, ein Format zu erzwingen. Wenn Ihr Prozess Nummern im internationalen Format braucht, bitten Sie in der **Description** darum und sichern Sie es mit einem Pattern ab.

## Was gespeichert wird

Text, die Nummer so, wie die befragte Person sie eingetippt hat. HireData formatiert sie nicht um.

## Logik-Operatoren

| Operator | Trifft zu, wenn |
|---|---|
| has response | die befragte Person überhaupt geantwortet hat |
| is equal to | die Antwort genau dem Wert entspricht |
| is not equal to | die Antwort irgendetwas anderes ist |
| starts with | die Antwort mit dem Wert beginnt |
| ends with | die Antwort mit dem Wert endet |
| contains | der Wert irgendwo in der Antwort vorkommt |
| does not contain | der Wert nirgendwo in der Antwort vorkommt |

![Der Logic-Tab mit geöffneter Operator-Auswahl auf einer Phone-Number-Bedingung, mit has response, is equal to, is not equal to, starts with, ends with, contains und does not contain](/images/forms-builder/fields/operators-phone-number.png)

## Evaluation

Schalten Sie **Criteria**, **Scoring** oder **Skills** für das Formular im [Evaluation-Tab](/de/reference/forms/evaluation/overview) ein, und jeder davon erhält einen Schalter auf dieser Karte. Eine Nummer ist selten eine Evaluation wert, deshalb lassen die meisten Formulare hier alle drei aus.
