Number nimmt eine einfache Zahl auf: Jahre an Erfahrung, Stunden pro Woche, die Anzahl von etwas. Es ist einer von nur zwei Typen, die die Logik vergleichen kann – damit ist es das Feld der Wahl, wenn eine Regel eine Antwort abwägen statt abgleichen muss.

Es befindet sich in der Gruppe **Numeric** der **Add Content**-Palette.

## Einstellungen

Die Karte enthält die [Einstellungen, die alle Felder gemeinsam haben](/de/reference/forms/overview#settings-every-field-shares). Number ergänzt vier eigene.

- **Placeholder**, bis zu 255 Zeichen, angezeigt im leeren Feld.
- **Minimum Value** und **Maximum Value**, die Enden des Bereichs, den Sie akzeptieren.
- **Steps**, die Größe eines Schritts. Setzen Sie sie auf 1, um ganze Zahlen zu erzwingen.

Die Meldungen, die eine befragte Person sieht, wenn eine Antwort außerhalb des Bereichs liegt, stehen unter **Validation** in [Sprachen und Übersetzungen](/de/reference/forms/overview#localization), als **Min Number** und **Max Number**.

## Was gespeichert wird

Eine Zahl.

## Logik-Operatoren

| Operator | Trifft zu, wenn |
|---|---|
| has response | die befragte Person überhaupt geantwortet hat |
| is equal to | die Antwort genau dem Wert entspricht |
| is not equal to | die Antwort irgendetwas anderes ist |
| is greater than | die Antwort über dem Wert liegt |
| is less than | die Antwort unter dem Wert liegt |
| is greater than or equal to | die Antwort dem Wert entspricht oder darüber liegt |
| is less than or equal to | die Antwort dem Wert entspricht oder darunter liegt |

![Der Logic-Tab mit geöffneter Operator-Auswahl auf einer Number-Bedingung, mit has response, is equal to, is not equal to und den vier Vergleichsoperatoren](/images/forms-builder/fields/operators-number.png)

<Warning>
  Ein als Pflichtfrage gesetztes Number-Feld blockiert die Antwort 0. **Next** tut nichts und keine Meldung erscheint. Bis der Fix ausgeliefert ist, setzen Sie auf jedem verpflichtenden Number-Feld einen **Minimum Value** von 1, damit 0 mit einer Meldung abgelehnt wird, die die befragte Person lesen kann.
</Warning>

## Evaluation

Schalten Sie **Criteria**, **Scoring** oder **Skills** für das Formular im [Evaluation-Tab](/de/reference/forms/evaluation/overview) ein, und jeder davon erhält einen Schalter auf dieser Karte.

Number passt besser zu **Scoring** als jeder andere Typ. Ein Schwellenwert gibt die volle Punktzahl, ein niedrigerer einen Teil, und alles darunter nichts – alles aus dem Wert selbst.
